# RunTrack 2 : PHP & MySQL

**Note** : Ce projet a été réalisé dans le cadre de ma formation de Développeur Web et Web Mobile (DWWM) au sein de La Plateforme.

Ce dépôt regroupe l'ensemble des exercices du RunTrack 2, axé sur l'apprentissage du langage PHP et des bases de données MySQL (MariaDB). Les travaux illustrent une progression allant des concepts fondamentaux de la programmation back-end jusqu'à la manipulation de données relationnelles.

## Contenu du dépôt

- **jour01 à jour04** : Bases de l'algorithmie et syntaxe PHP (variables, conditions, boucles, tableaux, et transmission de données via GET/POST).
- **jour05 à jour08** : Concepts avancés en PHP (fonctions, gestion des formulaires, sessions et cookies).
- **jour09** : Introduction aux bases de données avec MySQL (MariaDB). Ce dossier contient les scripts SQL d'export (`.sql`) illustrant des requêtes simples à complexes (CRUD).

## Installation et utilisation

1. Clonez le dépôt sur votre machine locale :
   ```bash
   git clone https://github.com/geoffrey-carpentier/runtrack2.git
   ```
2. **Pour le code PHP (jour01 à jour08)** : Il est nécessaire d'utiliser un environnement de serveur web local (tel que WAMP, XAMPP ou MAMP). Placez le dossier cloné dans le répertoire racine de votre serveur (ex: `C:\wamp64\www` ou `htdocs`), puis exécutez les fichiers depuis votre navigateur via `http://localhost/runtrack2/`.
3. **Pour le code SQL (jour09)** : Les fichiers `.sql` peuvent être importés directement dans votre SGBD (comme phpMyAdmin, DBeaver ou MySQL Workbench) pour recréer la structure et tester les requêtes.
